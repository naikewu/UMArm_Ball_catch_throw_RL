# V15 专用残差 RL 第一版

本版从 `teacher_runs/v15_improved/bc_v1_formal/bc_best.pt` 初始化，运行 V15 控制框架内的 PPO。正式长训练由用户启动；小规模工程验证结果与正式性能结论分开记录。

## 1. 目前起点与本轮目标

BC 已完成 60 轮，最佳 checkpoint 为第 54 轮。200 个独立配对场景中：

| 指标 | Teacher | BC |
|---|---:|---:|
| 抓取/释放 | 88.0% | 87.5% |
| 15 cm 命中 | 86.5% | 86.5% |
| 成功落地平均误差 | 4.882 cm | 4.925 cm |
| 最差参数区间命中率 | 76% | 74% |

BC 的模仿保真度可作为 RL 初始策略，但先前绝对最差区间 80% 门槛没有通过。该结论继续保留。RL 要在维护抓取、释放和落点精度的前提下，尝试降低接球相对速度、冲击和压力消耗代理，并检查困难场景鲁棒性。

每个历史参数区间只有 50 个测试场景，低命中率还不能证明某个目标距离或来球速度导致失败。训练保留全范围场景，额外分配 25% 新场景到 5.0-5.25 m/s 来球区域；不复用那 200 个测试轨迹或种子。测试仍覆盖完整分布。

## 2. 网络能调整什么

Actor 仍为 `82 -> 256 SiLU -> 256 SiLU -> 10`，从 BC 初始化。Critic 为 `113 -> 256 SiLU -> 256 SiLU -> 1`；其输出层从零开始拟合回报。Actor 的观测归一化保持 BC 训练集统计，不新增真实球状态或冲击力输入。Critic 可以使用原有特权状态。

动作执行沿用原有公式：

```text
applied = teacher + 0.25 * clip(policy - teacher, -LIMITS, LIMITS) * phase_mask
```

| 实际调整项 | 默认物理修正范围 |
|---|---:|
| 三维接球拦截偏移 | 每轴约 +/-3.75 mm |
| 接球速度匹配比例 | +/-0.0125 |
| 共收缩压力 | +/-0.25 psi |
| 绕转阻尼参数 k_r | +/-0.25 |
| 解析释放器方位偏置 | +/-0.25 度 |
| 闭合提前时间参数 | +/-1.25 ms |

V15 自适应控制器会覆盖动作索引 5、6 的绕转半径与驱动力。本版保持目标距离条件化半径和 10 N 驱动力配方，将这两个输出排除出 PPO 概率、熵、KL 和 BC 辅助损失，并使用确定性均值填充其动作历史。其余动作按阶段启用。

PID、简单逆动力学、压力限幅、解析释放器、抓取判据、物理场景和固定缓冲参数继续执行。网络没有直接控制阀门，也没有独立学习释放触发时刻或减速时间。默认动作权限较小，能否明显降冲击需要实验验证；本轮不自动扩大权限。

## 3. 奖励和保护

任务奖励继承 V15：抓取 +5，主动释放 +5，落地精度连续奖励最高 +20，15 cm 命中另加 +20，未落地终止 -10，以及原有小幅残差惩罚。

新增质量代价以累计量的增量逐步扣除：

| 量 | 归一化尺度 | 系数 |
|---|---:|---:|
| weld 峰值 | 400 N | 0.8 |
| 接住后前 50 ms 的 weld 冲量 | 3 N s | 0.6 |
| 首次抓取时相对速度 | 5 m/s | 0.8 |
| 全回合平均指令压力积分 | 270 psi s | 0.4 |
| 实体接触冲量 | 1 N s | 0.4 |

每个归一化量限制在 [0, 2]，默认单回合新增代价最多 6 分。`QualityWeight=0` 可关闭新增代价，范围为 [0, 1]。这些系数是首轮工程设置，不是最优权重或严格约束优化保证。

压力积分是消耗代理，不等于真实耗气量或能量；weld 载荷也不同于手指实体接触力，报告分别记录。任务奖励和模型筛选共同约束漏接与精度退化。

PPO 同时加入 BC 辅助损失和相对冻结 BC 的 KL 约束。零动作阶段只训练 Critic，不计入 Actor 的 PPO 均值或优势归一化。Critic 与 Actor 分别裁剪梯度，避免未训练 Critic 的大误差压低 Actor 更新。

## 4. 默认训练参数

| 参数 | 值 |
|---|---:|
| PPO updates | 100 |
| 新仿真回合 / update | 8 |
| 总训练回合 | 800 |
| 并行仿真 worker | 8，各 1 个 Torch 线程 |
| 学习进程 Torch 线程 | 4 |
| Actor / Critic 学习率 | 3e-5 / 3e-4 |
| gamma / GAE lambda | 0.999 / 0.98 |
| PPO clip / update epochs / minibatch | 0.10 / 3 / 256 |
| PPO 目标 KL / entropy 系数 | 0.01 / 0.0001 |
| BC 辅助损失 / anchor KL 系数 | 1.0 / 0.05 |
| 最大梯度范数 | 1.0，Actor/Critic 分别计算 |
| 验证 | 固定 80 个新场景，每 10 updates 及最后一次 |

每个训练 update 使用当前策略采集完整新轨迹，再做 PPO；不使用旧策略缓存冒充 on-policy 数据。失败回合保留。GAE 在每个真实终止边界截断，不把下一回合回报串入本回合。

训练随机种子默认 20260930；仿真种子从 100001 开始，每回合使用独立随机采样种子。固定验证从 2000001 开始；最终测试从 3000001 开始。种子重叠检查覆盖 BC 示范、teacher 搜索、已有独立 audit、BC 评估、RL 训练和验证。

默认总计算包括：800 个训练仿真回合、80 个 BC 验证基线回合、10 次各 80 个 RL 验证回合，共 1680 个仿真回合。最终 Teacher/BC/RL 各 200 回合另计 600 回合。该过程会明显慢于 53 秒左右的离线 BC。

## 5. 启动、续训和评估

在工程根目录 PowerShell 中启动：

```powershell
& '.\RL PPO\START_V15_RL.ps1' -Mode Train
```

默认输出：`RL PPO/teacher_runs/v15_improved/rl_v1_formal`。首先计算 80 回合 BC 验证基线，再开始更新。进度会显示 `validation_bc`、`train_1` 等阶段。

中断后继续：

```powershell
& '.\RL PPO\START_V15_RL.ps1' -Mode Resume
```

每个完成的 update 都保存 `ppo_latest.pt`，包含模型、优化器、随机数状态、最佳模型记录、数据/配方/源码契约。中断时未提交的 update 会使用相同场景种子重跑。若首次 BC 基线尚未算完、还没有 `ppo_latest.pt`，重新执行原来的 `Train` 命令即可。

`Updates` 表示累计目标次数。例如完成 100 次后续训到 200 次：

```powershell
& '.\RL PPO\START_V15_RL.ps1' -Mode Resume -Updates 200
```

续训要求原有训练参数、数据、BC、源码和验证场景一致；可修改 worker 数、累计 Updates。改变学习率或奖励应建立新实验目录。本次交付只执行了小规模流程验证，正式长训练通过上方 Train 命令启动。

训练完成后评估最佳模型：

```powershell
& '.\RL PPO\START_V15_RL.ps1' -Mode Evaluate -Workers 8
```

生成 `rl_v1_formal/evaluation_200/comparison.json`，比较 Teacher、BC、RL。默认评估 `ppo_best.pt`。重复完全相同的评估可复用已完成的整组 Teacher/BC/RL 记录；更换模型或测试配置时必须使用新输出目录。测试集用于最终报告，后续调参后应换新测试种子及输出目录。

需要自由指定测试输出和 design seed，可在 `RL PPO` 目录使用：

```powershell
..\.venv\Scripts\python.exe -m teacher_rl.improved_rl evaluate --checkpoint teacher_runs/v15_improved/rl_v1_formal/ppo_best.pt --seed 3100001 --design-seed 20261002 --out teacher_runs/v15_improved/rl_v1_formal/evaluation_new
```

## 6. 最佳模型和报告怎么看

`ppo_best.pt` 初始就是 BC 权重；`ppo_latest.pt` 是最后一个完成的 PPO update，两者可能不同。

候选先通过相对 BC 的门槛：抓取、释放、15 cm 命中率分别下降不超过 2 个百分点；平均落点误差不超过 7 cm 且较 BC 增加不超过 1 cm；共同命中回合上的 weld 均值、P95、冲量和压力积分相关门槛不退化超过 5%；全体回合最大实体接触峰值较 BC 增加不超过 10 N。

合格候选按命中数、抓取数、释放数优先排序；相同时比较共同命中回合的质量得分，再比较落点误差。质量得分由 BC 归一化后的 weld 峰值、前 50 ms 冲量、相对速度、压力积分和接触冲量组成，权重为 0.30/0.25/0.25/0.15/0.05。均在双方共同命中回合上计算，避免漏接导致载荷降低被当成改善。

- `eligible=true`：通过相对 BC 的保护门槛。
- `quality_improved=true`：通过门槛且配对质量得分至少改善 3%，仍需结合样本数量判断。
- `absolute_generalization_pass=true`：另外要求至少 80 回合、每个参数区间至少 10 回合，且最差区间命中率达到 80%。
- `best_is_bc_initialization=true` 或 `best_update=0`：没有选出优于初始 BC 的策略，不能声称 RL 已改善。

`update_*.json` 保存每轮 PPO 指标和训练回合；`validation_*.json` 保存固定验证结果；`run_config.json` 保存契约；`training_summary.json` 表示本次目标更新已完成。不同 `checkpoints/selected_*.pt` 保留入选版本；best 指针在 latest 提交后发布，续训时会恢复到已提交的最佳版本。

实验使用同一固定验证集选模，会产生选择偏差。最终泛化、柔顺改善和精度结论应以新的完整分布测试为依据；仍不代表全局最优或实机性能。

## 7. 本次实际验证

- 完整回归测试：70 项通过。包含新增奖励上限、阶段动作掩码、PPO Actor/Critic 更新、采样可达性、seed 隔离、选模门槛和断点恢复测试。
- 连续两次更新与中间保存/恢复的两次更新，模型参数逐项完全一致。
- 关闭质量惩罚时，完整回合与原 V15 的轨迹、观测、奖励逐项一致。
- PowerShell 真实 smoke：先训练 1 次更新，恢复后再更新 1 次；共 8 个新训练回合，每次更新后在固定 5 场景验证。第一轮 1522 个决策步，第二轮 1949 个决策步；损失均为有限值。
- 另取 5 个新场景比较 Teacher/BC/第二轮 RL，三者抓取、释放和 15 cm 命中均为 4/5，平均落点误差分别为 2.970/3.067/3.081 cm。RL 通过该小样本的相对保护门槛，但未达到质量改善 3% 或正式泛化判据。
- `best_update=0`：当前 smoke 的最佳模型仍是 BC 初始化。它说明保存和筛选流程正常，不能声称 RL 已改善。

上述结果在 `teacher_runs/v15_improved/rl_v1_smoke/`，评估在 `evaluation_5/comparison.json`；不作为正式长训练产物。正式输出目录 `rl_v1_formal` 尚未启动。原 V15 teacher 指纹保持为 `f85697a51bd23440fa97902993ba90ff04193c21fe97aeb167dc7ff5d13ce03f`。
