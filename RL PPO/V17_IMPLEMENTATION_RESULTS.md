# V17 第一阶段修改与验证结果

日期：2026-09-19。此次完成双向压力、独立Kp/Kd和接球后缓冲通道，不代表已完成后续释放预测修复、抛球残差或联合优化。

## 已完成的修改

- 独立V17环境、7维残差网络、训练/评估入口与输出目录；原V15/V16不改动。
- 默认压力权限为相对基线+/-1 psi，可通过敏感性入口检查2或3 psi；不是原来的单向降压。
- Kp与Kd独立缩放，Ki固定；低层滤波和压力残差变化率限制。
- 接甩后的轨道压力、Kd真实参与控制；末段锁定动作并平滑淡出，避免只解除无效动作掩码。
- 保存请求动作、滤波参数、有效控制参数、最终压力和测量压力；增加50-300 ms载荷统计。
- 保留成功率、精度、受力、实体接触和连续性门槛，另加关节偏转保护比较、初始峰值P95及后续缓冲载荷检查。

这说明新控制量确实能改变闭环结果，但不能直接选用某个极端动作：压力+1 psi虽然降低抓取约束峰值和冲量，却产生最大219.56 N实体接触峰值，未通过接触保护。降低Kp则出现峰值下降、初始冲量上升的折中。接球后缓冲不会改变已经发生的瞬时初始峰值，对后续载荷的影响在本组中较小，尚无明显改善证据。

连续零残差的精度与关节偏转比较未通过门槛，因此未生成 `control_screen_v1/selected_config.json`，没有授权正式训练。关节保护本来就是软保护，不能用“命中5/5”替代完整验收。

本组原BC最大关节偏转32.259°，连续零残差40.573°，不是小幅数值波动。最终日志核对确认接球和缓冲压力动作分别可达到约-1、+1 psi，Kp覆盖约0.7-1.1倍、Kd约0.8-1.3倍，缓冲结束恢复名义参数。所有压力指令保持1-30 psi不意味着关节运动已满足验收要求。

## Smoke结果

训练5/5命中，固定5场景验证为4/5命中，原BC和连续零残差在该验证集也均4/5。一次更新后的初始峰值、初始冲量和峰值P95相对连续基线略增，未被选为best；不构成RL改善。

2033个决策样本，252个有效动作样本；近似KL 0.00104，无KL提前停止。Actor梯度范数约2.78、Critic约19.49，Critic解释方差0.0365。完整调用耗时175.74 s，包括基线评估、训练和更新后评估，不是单独的反向传播耗时。

Smoke只允许最多2次更新、每次8回合、10个验证场景，不能扩展为绕过基线门槛的长训练。正式训练尚未启动，测试进程已结束。
