# V20 受限轨迹与预测释放教师筛选

## 目标

V19已经证明即时连续交接正常，但单独提前限制关节幅度会破坏稳定释放。V20保持V15的接球控制、24帧传感器球状态拟合、即时交接和接触质量门槛不变，只在接球后共同筛选：

- 受限关节幅度下的轨道力、半径和spin-up节奏；
- 基于新鲜传感器拟合球状态、阀门延迟、预测落点与受限出手速度校准的确定性释放顾问。

释放顾问不是RL动作，不读取仿真器的真实球状态；只有预测落点误差、出手速度与仰角达标，并且实测关节角不超过候选安全阈值时才打开夹爪。`release_speed_gain`是对手持状态到阀门实际放球之间速度损失的保守校准，在独立验证中仍须通过实际落点门槛。

## 第一步：20场景筛选

从项目根目录运行：

```powershell
& '.\RL PPO\START_V20_TEACHER.ps1' -Mode Screen
```

默认运行BC和5个V20教师候选，各20个未使用场景，共120条仿真。结果写入`RL PPO/teacher_runs/v20_trajectory_release/screen_v1/`。可以中断后使用完全相同的命令续跑；不要在同一输出目录改变代码、种子或场景数量。

候选必须同时保持BC的抓住、释放、15 cm命中数和接触质量，在平均落点误差上不比BC差5 mm，最大关节偏转不超过36度，接球后立即进入轨道且没有持续停顿。此外，每一次实际释放都必须由V20预测顾问调度。

没有`selected_config.json`时，筛选失败；不要采集新BC数据、启动80场景验证或启动RL。

## 第二步：80场景独立验证

只在第一步写出`selected_config.json`后运行：

```powershell
& '.\RL PPO\START_V20_TEACHER.ps1' -Mode Validate
```

这会在80个全新场景中将BC和入选V20教师配对比较。只有通过任务、落点、关节、接触、无停顿和最差参数分箱门槛，才会写出`qualified_teacher.json`。

只有得到该文件，才适合以这个教师采集新的BC数据，并随后开启仅作用于甩动轨迹的小范围残差RL；接球柔顺性仍须作为单独阶段开放与验收。
