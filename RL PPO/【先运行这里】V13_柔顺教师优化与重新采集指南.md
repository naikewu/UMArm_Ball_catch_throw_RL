# 【先运行这里】V13 柔顺教师优化与重新采集指南

当前 V15 已完成 1000 回合采集与 BC 闭环评估。下一步残差 RL 的参数、启动和续训命令见 [V15 残差 RL 训练指南](【先运行这里】V15_残差RL训练指南.md)。以下保留 V13 历史流程。

日期：2026-09-17。

## 1. 需要重新采集吗？

需要。旧96回合演示的是原教师，不能给BC提供新优化的降压、速度匹配和缓冲行为。顺序是：

```text
配对搜索教师参数 -> 在另一组来球上验证 -> 采集新教师示范 -> 重新训练BC -> 独立闭环对比
```

V12数据、模型和训练结果保留。V13使用独立schema和目录，避免新动作标签进入旧训练脚本。

## 2. 你现在运行什么

在工程根目录PowerShell中，首先运行教师参数搜索：

```powershell
& '.\RL PPO\START_SOFT_TEACHER_V13.ps1' -Mode Search -Workers 4
```

默认比较9组参数，每组12个相同来球，共108回合；取两组候选与基线，在另外24个相同来球上复核，共72回合。合计180个完整抓抛回合。种子：筛选40001起，复核50001起。

输出：`RL PPO/teacher_runs/v13/search/selected_recipe.json`。

- `improved=true`：在这组有限验证样本上符合当前改进判据，可以继续采集。
- `improved=false`：没有候选通过判据，自动保留原教师。此时应先分析结果、扩展搜索，不建议直接把基线重新采集当成柔顺性进步。采集命令仍可执行，但会明确提示它采集的是基线。

搜索中断后重复同一命令即可，已完成回合按配置和源代码指纹复用。当前活动工作进程可能需要先完成一个回合才退出。

选出改善方案后依次运行：

```powershell
& '.\RL PPO\START_SOFT_TEACHER_V13.ps1' -Mode Collect -Episodes 256 -Workers 4
& '.\RL PPO\START_SOFT_TEACHER_V13.ps1' -Mode BC
& '.\RL PPO\START_SOFT_TEACHER_V13.ps1' -Mode Evaluate -Episodes 96 -Workers 4
```

采集种子60001起，每个完整回合保存NPZ轨迹和JSON事件/指标，成功失败全部保留。默认256回合中，205回合训练、51回合验证，按种子是否能被5整除划分。BC训练60个epoch，只使用训练集计算归一化。

最终评估种子70001起，对原教师、优化教师、BC分别运行同样96回合，共288回合。它不重新训练网络，结果保存在 `teacher_runs/v13/evaluation/comparison.json`。最终测试集不应反复拿来调参；之后调整配方时另留新测试种子。

## 4. 教师怎么变柔软

本版仍使用原来的球、抓取半径、软weld、压力分配和投掷器。优化项作用在控制命令与轨迹上。

1. 接球速度匹配比例：从0.3基线试0.35和0.40。
2. 接触附近的共收缩压力：原18 psi基础上试降低2或4 psi。
3. 压力窗口：预计到达前0.20秒到到达后0.25秒，进入和退出各用0.10秒平滑变化；抓取后冻结到达时间估计，避免窗口跟着持球估计漂移。
4. 接住后减速：原0.3秒试0.5秒，同时制动阻尼从8试6。
5. 接球阶段反馈增益：试原值的0.85倍，验证控制器是否因强反馈抵消降压效果。

9组包括原教师、单项修改及少量组合。配方还支持加速时间、回中时间等参数，但默认小规模搜索没有把所有维度一起展开。这是可解释的第一轮候选比较，不是全局最优搜索。

降压窗口通过独立适配器在控制器更新减速计划后施加，避免原控制器的 `stop()` 重置压力而取消降压。压力调度有平滑边沿，原压力变化限制仍运行。

加快速度匹配、降低压力、延长减速都可能导致新的失败，所以优化后仍必须运行完整投掷及落地评分。

## 5. 怎样判断确实改善

新增记录：

- 物理子步检测到的首次持球时刻。
- 抓取前一个物理子步的球与抓取中心相对速度估计。
- weld峰值及发生时刻、实体接触峰值发生时刻。
- 抓取后前50 ms的weld峰值和力幅值积分。
- 全回合weld力幅值积分。
- 抓取后前1秒末端相对抓取位置的最大位移，包含可能的回中运动。
- 压力调度细轨迹 `pressure_schedule150`：时间、接球控制器共收缩设定值、巡航计划速度。

末端速度由真实抓取中心位置做物理子步差分，仅用于离线诊断，不作为Actor新输入。前50 ms冲量是约束力幅值积分，不能等同于真实手指接触冲量；原实体接触冲量同时保留。

候选与基线使用相同种子配对比较。当前工程判据：

- 抓取、释放、15 cm命中数量不下降，且不能丢失原本命中的种子。
- 成功落地回合平均误差增加不超过1 cm。
- 成功回合weld峰值的P95增加不超过5%。
- 所有回合最大实体接触峰值增加不超过10 N，成功回合平均实体接触冲量增加不超过0.05 N·s。
- 在双方均正常释放并落地的配对回合上，压力积分增加不超过5%。
- 在上述配对回合上，将平均weld峰值、前50 ms约束冲量和压力积分分别除以基线，再按0.5、0.3、0.2加权；总指标至少下降3%才标为 `improved`。

这些是明确的实验筛选阈值，不是物理安全证明或统计显著性结论。报告保留各项数值、失败种子、未通过原因和配对样本数，避免用“漏接导致力变小”冒充改进。

压力积分仍是消耗代理，不是真实用气量或能量。手指接触与weld载荷分开记录；不修改weld刚度或抓取半径来人为降低峰值。

## 6. BC学什么，哪些仍由教师执行

网络保持Actor `82 -> 256 -> 256 -> 10`，Critic结构保留但本轮BC不训练Critic。

动作标签包括动态抓取位置、配方速度匹配比例和随时间变化的共收缩压力。BC运行时保留优化教师及原有有界修正机制，默认authority仍为0.25。

减速时间、回中时间、压力窗口宽度和反馈增益是随checkpoint保存的固定教师配方，尚未变成网络输出。因此本版学到的是优化教师上的动作意图，并未让网络独立规划完整缓冲轨迹。

checkpoint保存配方、任务配置、数据清单和V13源指纹。评估要求模型与配方一致；不同配方不混在同一数据集里。V13模型不能直接交给旧 `START_TEACHER_RL.ps1` 继续PPO。

本阶段先完成教师优化与BC闭环验证。以后增加PPO时，需要把有效缓冲参数接入动作空间、校准质量奖励尺度，并修复选模与周期checkpoint保存；本次没有自动开始下一轮PPO。

